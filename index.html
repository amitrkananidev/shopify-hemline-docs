Everything you need to set up Hemline.

Hemline is a premium fashion theme for Shopify Online Store 2.0: five colour schemes, a mega menu, bundles, lookbook hotspots, subscriptions, pickup and more — all from the theme editor, no code.

1. Setup in 10 minutes

1
Install. Online Store → Themes → Add theme → Upload zip (or install from the Theme Store). Click Publish when you're ready; until then use Customize to preview.
2
Menus. Content → Menus. Create Main menu (header) and Footer menu. Nest items under a parent to get a mega menu (see §4).
3
Pages. Content → Pages → Add page. For Contact choose template page.contact; for FAQ choose page.faq. Add them to your menus.
4
Filters. Install the free Shopify Search & Discovery app and switch on the filters you want (size, colour, price…). Hemline reads them automatically.
5
Colours & fonts. Customize → Theme settings → Colours. Pick a scheme per section with the "Colour scheme" setting at the top of every section.
6
Homepage. Customize → Home page. Click each section to pick collections, products and images. Sections auto-fill from your catalogue until you do.
7
Policies. Settings → Policies. Hemline links them in the footer and renders them with the policy template.

3. Colour schemes

Each scheme is 11 tokens. Sections choose a scheme; nothing is hard-coded, so a Noir hero over an Ivory page just works.

SchemeMoodAccent
IvoryWarm editorial — defaultRust
NoirLuxury, nightGold
SageNatural, slow fashionForest
BlushFeminine, beautyRaspberry
OceanCrisp, sport, menswearCobalt

Tokens: background, surface (cards), tint, tint 2 (deep), lines, text, muted text, accent, text on accent, accent 2 (blocks), text on accent 2. Keep body text ≥ 4.5:1 contrast against background.

4. Menus & mega menu

The header reads Main menu. Any top-level item that has children opens a mega menu: each child becomes a column heading, grandchildren become the links. Three levels are supported.

Main menu
├─ New in
├─ Women            ← has children → mega menu
│  ├─ Outerwear     ← column
│  │  ├─ Coats
│  │  └─ Jackets
│  ├─ Knitwear
│  └─ Tailoring
├─ Men
└─ Editorial

Promo images in the mega menu: Customize → Header → Add block → Mega menu promo. Set "Attach to menu item" to the exact title (e.g. Women) and add up to two images with links.

Highlight one item (e.g. "New in") in the accent colour: Header → "Highlight this menu item".

On mobile the same menu becomes a multi-level accordion in the side drawer.

6. Product page

The product page is made of blocks you can reorder or remove: Title & price · Short description · Variant picker · Buy buttons · Trust icons · Pincode check · Collapsible rows · Complementary products · Custom Liquid · Description · Share.

Variants

Options named Colour or Color render as swatches; Size gets a size-guide link (pick the page in the Variant picker block). Unavailable combinations are struck through. Variant images switch the gallery.

Subscriptions

Install any selling-plan app (e.g. Shopify Subscriptions). Plans appear automatically above Add to bag with the discount shown.

Pickup

Enable local pickup under Settings → Shipping. Availability shows per variant below the buttons.

Shop Pay Installments

Enable in Settings → Payments. The banner appears under the buttons.

Gift cards

Gift card products show a "Send as a gift" form (recipient email, message, send date).

Low stock

"Only N left" appears when inventory ≤ the threshold in Theme settings → Product cards.

Complementary products

Set them in Search & Discovery → Product recommendations → Complementary. Shown as a compact list in the buy box.

7. Collections & filters

Filters come from Shopify Search & Discovery (free). Sorting, 2–5 column grid, a promo tile inside the grid, and an SEO text block (set per collection via metafield custom.seo_text or globally in the section) are built in.

Sub-collection chips: create a menu whose handle matches the collection handle (e.g. menu handle outerwear for /collections/outerwear) and it appears as chips above the grid. Or pick a menu in the section settings.

8. Cart

Drawer (default) or page — Theme settings → Cart. Both support quantity changes, removal, discounts, order notes, a free-shipping progress bar, an upsell product and payment badges. Express checkout buttons show on the cart page.

9. Promo tools

  • Countdown — ends at the date/time you set, in each visitor's local time. Optionally hides itself when done.
  • Bundle — the % shown is display only; create an automatic discount (Discounts → Create → Amount off products → applies to those products) so checkout matches.
  • Lookbook hotspots — set X/Y per hotspot; preview updates live in the editor. "Add all" adds every tagged product (first available variant).
  • Before / after — use two images with the same framing.

FAQ

Products aren't showing on the homepage

Click the section and pick a collection. If no collection is chosen Hemline uses "All products" — make sure at least one product is Active and available on the Online Store sales channel.

The filter button shows nothing

Install Shopify Search & Discovery and turn on at least one filter. Filters appear within a minute.

How do I change the logo?

Customize → Header → Logo. Leave empty to use your store name as a wordmark.

Can I use my own fonts?

Choose any font from Shopify's library in Theme settings → Typography. Custom font files aren't supported by Theme Store themes; a developer can add them via Custom Liquid.

Why is the mega menu not opening?

Only menu items that have child items open a mega menu. Add children under the item in Content → Menus.

How do I show reviews from my app?

Product page → Add block → pick your app's block. Use the manual "Reviews" section only for hand-written quotes.

Checkout looks different from the theme

Checkout is hosted by Shopify. Match colours and fonts under Settings → Checkout.

How do I get updates?

Theme Store purchases get updates in Online Store → Themes (an "Update" button appears). Your settings and content are kept.
